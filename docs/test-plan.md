# E-commerce Application – Test Plan

## 1. Project Overview

The purpose of this project is to test an e-commerce web application that allows users to browse products, create accounts, log in, manage shopping carts, and place orders.

The project will demonstrate practical experience in manual testing, API testing, and test automation using Python and Playwright.

## 2. Testing Objectives

The main objectives are:

- Verify that all major application functionalities work as expected.
- Identify and document software defects.
- Validate API endpoints and data responses.
- Automate critical user workflows.
- Verify application behavior under different test conditions.
- Integrate automated tests into a CI/CD pipeline.

## 3. Application Scope

### In Scope

- User registration and authentication.
- Product catalog and search.
- Product details.
- Shopping cart management.
- Checkout and order placement.
- Order history.
- API functionality.
- UI functionality and usability.

### Out of Scope

- Real payment processing.
- Production database administration.
- Third-party delivery services.
- Performance and security penetration testing.

## 4. Testing Types

- Functional Testing
- Regression Testing
- Smoke Testing
- UI Testing
- API Testing
- Negative Testing
- Exploratory Testing

## 5. Test Environment

The initial test environment will include:

- Operating System: Windows 11
- IDE: Visual Studio Code
- Programming Language: Python
- UI Automation: Playwright
- Test Framework: Pytest
- API Testing: Postman
- Version Control: Git and GitHub

## 6. Entry Criteria

Testing can begin when:

- The application is accessible.
- The required test environment is configured.
- Test scenarios and test cases are prepared.
- The application requirements are available.

## 7. Exit Criteria

Testing can be considered complete when:

- All planned test cases have been executed.
- Critical and high-priority defects have been documented.
- Critical automated tests pass.
- Test results have been documented.
- No unresolved critical defects remain.
