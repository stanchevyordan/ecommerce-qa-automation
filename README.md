# E-commerce QA Automation

## Project Overview

This project demonstrates practical knowledge of Software Quality Assurance (QA), including manual testing, API testing, and test automation.

The goal is to develop a structured QA testing project covering different aspects of an e-commerce application.

## Technologies

- Python
- Pytest
- Playwright
- Postman
- Git
- GitHub Actions

## Project Scope

The project will include:

- Manual test documentation
- Test scenarios and test cases
- Bug reports
- API testing collections
- Automated API tests
- Automated UI tests
- CI/CD integration

## Project Status

Currently in development.
